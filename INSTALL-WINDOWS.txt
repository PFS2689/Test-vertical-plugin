Vertical Shorts Plugin for OBS Studio — Windows Install (v1.0.0)
===============================================================

Requirements
------------
- Windows 10/11 64-bit
- OBS Studio 30 or newer (31+ recommended)

One-click install (recommended)
-------------------------------
Download and run:

  https://github.com/PFS2689/vertical-shorts-plugin/releases/latest/download/VerticalShortsPlugin-Setup.exe

1. Close OBS Studio completely.
2. Run VerticalShortsPlugin-Setup.exe (no admin required).
3. Start OBS Studio → View → Docks → Shorts.

Zip install
-----------
1. Close OBS Studio completely.
2. Press Win+R, paste this, and press Enter:

   %APPDATA%\obs-studio\plugins

3. If the "plugins" folder does not exist, create it.
4. Copy the entire "obs-shorts-vertical" folder from this zip into that plugins folder.

   Final path should look like:

   %APPDATA%\obs-studio\plugins\obs-shorts-vertical\bin\64bit\obs-shorts-vertical.dll
   %APPDATA%\obs-studio\plugins\obs-shorts-vertical\data\locale\en-US.ini

5. Start OBS Studio.
6. Open View → Docks → Shorts.

Program Files install (optional)
--------------------------------
You can instead copy:

  bin\64bit\obs-shorts-vertical.dll
    → C:\Program Files\obs-studio\obs-plugins\64bit\

  data\*
    → C:\Program Files\obs-studio\data\obs-plugins\obs-shorts-vertical\

Uninstall
---------
Delete the obs-shorts-vertical folder from your plugins directory (or the DLL/data files
from Program Files) and restart OBS. Or use Windows Apps & features to uninstall if you
used the Setup installer.

Usage tip
---------
Add Camera (or Add Source), then drag to move and use the corner/edge handles to resize
just like the main OBS preview.
