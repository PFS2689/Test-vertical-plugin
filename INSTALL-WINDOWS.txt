Vertical Shorts Plugin for OBS Studio — Windows Install (v1.0.1)
===============================================================

Requirements
------------
- Windows 10/11 64-bit
- OBS Studio 30 or newer (31+ recommended)

Manual zip install (recommended)
--------------------------------
Download:

  https://github.com/PFS2689/Test-vertical-plugin/releases/latest/download/Vertical-Shorts-Plugin.zip

1. Close OBS Studio completely.
2. Press Win+R, paste this, and press Enter:

   %APPDATA%\obs-studio\plugins

3. If the "plugins" folder does not exist, create it.
4. Copy the entire "obs-shorts-vertical" folder from this zip into that plugins folder.

   Final path should look like:

   %APPDATA%\obs-studio\plugins\obs-shorts-vertical\bin\64bit\obs-shorts-vertical.dll
   %APPDATA%\obs-studio\plugins\obs-shorts-vertical\data\locale\en-US.ini

5. Start OBS Studio.
6. Open View → Docks → Vertical Shorts.

One-click install (optional)
----------------------------
  https://github.com/PFS2689/Test-vertical-plugin/releases/latest/download/VerticalShortsPlugin-Setup.exe

Uninstall
---------
Delete the obs-shorts-vertical folder from your plugins directory and restart OBS.
If you used the Setup installer, you can also uninstall from Windows Apps & features.

Usage tip
---------
Add Camera (or Add Source), then drag to move and use the corner/edge handles to resize
just like the main OBS preview.
